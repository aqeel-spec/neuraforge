## Implementation Standards

All Phase 5 components MUST:

1. **Framer Motion** — Use framer-motion for all animations
2. **Reduced Motion** — Respect `prefers-reduced-motion` (static fallback)
3. **SSR Safe** — No window/document in initial render
4. **TypeScript Strict** — Full type safety, exported interfaces
5. **Tailwind Only** — No CSS-in-JS for layout/colors (animations via framer-motion)
6. **Dark Mode** — All themes support light + dark
7. **Responsive** — Mobile-first, works at all breakpoints
8. **Composable** — Components work standalone or composed together
9. **< 10kB each** — Tree-shakeable, no heavy dependencies
10. **MCP Queryable** — Full metadata for AI agent discovery
